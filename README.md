# KernelLab - Simulador de SO
Projeto desenvolvido para a empresa MedControl Systems visando analisar gargalos de CPU, concorrência de dispositivos e falhas de paginação.

## Instalação
1. Clone o repositório.
2. Crie um ambiente virtual: `python -m venv venv` e ative-o.
3. Instale as dependências: `pip install -r requirements.txt`
4. Execute o simulador: `streamlit run src/main.py`

## Arquitetura e Algoritmos
- **Escalonamento de CPU:** Implementação de FCFS e SJF gerando Diagrama de Gantt.
- **Gerenciamento de Memória:** Implementação e simulação de FIFO e LRU.
- **Controle de Dispositivos:** Fila simulada com Mutex e Matriz de Controle de Acesso.
